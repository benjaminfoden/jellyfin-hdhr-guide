HDHomeRun TV Guide

Points Jellyfin's XMLTV listings provider at SiliconDust's guide feed for your HDHomeRun tuners. Each sync reads a fresh DeviceAuth token from every tuner below and updates the listings provider - this runs automatically on the "Sync HDHomeRun TV Guide" schedule (Dashboard > Scheduled Tasks > Live TV) and once whenever you save this page.

Comma-separated IP addresses or hostnames of any HDHomeRun tuners not already configured in Jellyfin, e.g. 192.168.1.50, 192.168.1.51
